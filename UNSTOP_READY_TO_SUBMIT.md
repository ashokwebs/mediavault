### Project Title
`MediaVault — Autonomous AI Digital Asset Optimization & E-Commerce Pipeline`

### Tagline / Short Pitch (One-liner)
`Turn raw product photos into studio-grade e-commerce assets with automated background removal, smart focal crop, and 92% bandwidth reduction using Cloudinary AI.`

### Project Description / Problem Statement
```markdown
E-commerce merchants, local retailers, and indie creators waste countless hours manually retouching product photos, cutting out backgrounds, and resizing media for mobile, desktop, and marketplaces. Heavy unoptimized images slow down page load times, directly harming conversion rates and mobile SEO rankings.

MediaVault solves this by providing an autonomous, one-click digital asset pipeline powered by Cloudinary's Programmable Media and AI transformation engine. Users upload raw camera photos, and MediaVault automatically:
1. Removes messy backgrounds with AI-powered alpha mask generation (`e_background_removal`).
2. Applies smart content-aware framing that identifies the focal product or model (`c_fill,g_auto`).
3. Enhances dynamic range, edge sharpness, and studio lighting (`e_improve,e_sharpen`).
4. Negotiates modern AVIF and WebP formats (`f_auto,q_auto`) to cut bandwidth by up to 92% without visible degradation.
```

### Key Features
```markdown
- **Autonomous Multi-Stage AI Transformations:** Raw assets are simultaneously processed for thumbnail, square marketplace (1:1), and vertical mobile story (9:16) formats in real time.
- **Bandwidth & Latency Analytics:** Visual comparative metrics showing byte reduction (from ~4.2 MB down to 320 KB) and Core Web Vitals speedup.
- **Instant E-Commerce Export:** One-click downloads of transparent PNGs, high-density WebPs, and production CDN URLs ready for Shopify, WooCommerce, and custom web stores.
- **Responsive Dark-Mode Interface:** Crafted according to modern 8pt spatial design systems and WCAG AA contrast standards.
```

### Tech Stack
```markdown
- **Frontend & App:** Next.js 15 (App Router), React 19, TypeScript
- **Styling & Design:** Tailwind CSS, Lucide React
- **Media Engine:** Cloudinary Programmable Media & Generative AI API
- **Deployment:** Vercel Edge Network
```
